<!-- OVERVIEW -->
<a name="overview"></a>
<h2 align="center">✨ A Workshop for Your Documents</h2>

<p align="center">
  <b>PDFMania</b> is a lightweight PDF toolkit built with
  <b>HTML, CSS, and JavaScript</b>.
  It brings everyday document operations into a single interface,
  from creating a PDF to combining files and removing unwanted pages.
</p>

<p align="center">
  Its cream background, gold accents, burgundy details, and serif typography
  give the workspace the character of a classic document workshop.
</p>

<p align="center">
  <b>Choose a tool. Add your content. Download the result.</b>
</p>

<!-- FEATURES -->
<a name="features"></a>
<h2 align="center">🧰 Seven Tools, One Workspace</h2>

<table align="center">
  <tr>
    <td width="50%" align="center" valign="top">
      <h3>📄 Create PDF</h3>
      <p>
        Build text-based documents with manually added pages.
        Customize the document title, text size, color, and margins.
      </p>
      <p>
        <code>A4</code>
        <code>A5</code>
        <code>Letter</code>
        <code>Legal</code>
      </p>
    </td>
    <td width="50%" align="center" valign="top">
      <h3>🔗 Merge PDFs</h3>
      <p>
        Combine two or more PDFs into one document.
        Pages are copied in the order of the selected file list.
      </p>
      <p>
        <code>Multiple files</code>
        <code>One PDF</code>
      </p>
    </td>
  </tr>

  <tr>
    <td width="50%" align="center" valign="top">
      <h3>✂️ Split PDF</h3>
      <p>
        Extract a page range, divide a document into groups of pages,
        or save every page as a separate PDF.
      </p>
      <p>
        <code>Page ranges</code>
        <code>Page groups</code>
        <code>Individual pages</code>
      </p>
    </td>
    <td width="50%" align="center" valign="top">
      <h3>🗑️ Remove Pages</h3>
      <p>
        Select unwanted pages using numbered page selectors
        and download a document containing the pages you keep.
      </p>
      <p>
        <code>Page selection</code>
        <code>Document cleanup</code>
      </p>
    </td>
  </tr>

  <tr>
    <td width="50%" align="center" valign="top">
      <h3>📝 Add Text</h3>
      <p>
        Overlay custom text with configurable size, color,
        and position. Apply it to all pages, the first page,
        or the last page.
      </p>
      <p>
        <code>Text overlays</code>
        <code>Position controls</code>
      </p>
    </td>
    <td width="50%" align="center" valign="top">
      <h3>💧 Add Watermark</h3>
      <p>
        Apply a text watermark across the document.
        Customize its text, size, color, opacity, and rotation.
      </p>
      <p>
        <code>Text watermarks</code>
        <code>Appearance controls</code>
      </p>
    </td>
  </tr>

  <tr>
    <td colspan="2" align="center" valign="top">
      <h3>📉 Compress PDF</h3>
      <p>
        Perform basic document optimization by clearing selected
        metadata fields and re-saving the PDF.
      </p>
      <p>
        <b>Current scope:</b> image downsampling is not implemented,
        and a smaller output file is not guaranteed.
      </p>
      <p>
        <code>Metadata cleanup</code>
        <code>PDF re-saving</code>
      </p>
    </td>
  </tr>
</table>

<p align="center">
  <b>Also included:</b>
  drag-and-drop file input, selected-file information,
  a first-page preview in the Add Text tool, and downloadable PDF outputs.
</p>

<!-- GETTING STARTED -->
<a name="getting-started"></a>
<h2 align="center">🚀 Run PDFMania Locally</h2>

<p align="center">
  The application is contained in <code>PDF Mania.html</code>.
  Serve the repository with a local static server to get started.
</p>

### 1. Clone the repository

```bash
git clone https://github.com/sdqxmd/PDF-Editing-Tool.git
cd PDF-Editing-Tool
```

### 2. Start a local server

With Python 3 installed:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

If your system uses the `python3` command:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

### 3. Open the application

Open **[PDFMania in your browser](http://127.0.0.1:8000/PDF%20Mania.html)**.

<p align="center">
  <sub>
    Any static web server can serve this project.
    An internet connection is needed to fetch the external PDF libraries and fonts.
  </sub>
</p>

<!-- CURRENT BEHAVIOR -->
<h2 align="center">📌 What to Expect</h2>

<table align="center">
  <thead>
    <tr>
      <th align="center">Tool / Area</th>
      <th align="center">Current Behavior</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td align="center"><b>Add Text</b></td>
      <td align="center">
        Adds text over the existing page content.
        Editing or reflowing existing PDF text is not implemented.
      </td>
    </tr>
    <tr>
      <td align="center"><b>Preview</b></td>
      <td align="center">
        The Add Text preview shows the first page of the selected input PDF.
        It does not show the pending text overlay.
      </td>
    </tr>
    <tr>
      <td align="center"><b>Create PDF</b></td>
      <td align="center">
        Add pages manually for longer documents.
        Automatic overflow pagination is not implemented;
        too much text on one page can overlap.
      </td>
    </tr>
    <tr>
      <td align="center"><b>Compression</b></td>
      <td align="center">
        Clears selected metadata and re-saves the PDF.
        Images are not downsampled, and output size may stay the same or increase.
      </td>
    </tr>
    <tr>
      <td align="center"><b>Remove Pages</b></td>
      <td align="center">
        At least one page must remain in the output document.
      </td>
    </tr>
    <tr>
      <td align="center"><b>Processing</b></td>
      <td align="center">
        Document operations run in browser JavaScript.
        Libraries and fonts are fetched from external services.
      </td>
    </tr>
  </tbody>
</table>
